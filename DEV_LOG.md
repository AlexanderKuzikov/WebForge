\### \*\*День 0: Инициализация проекта и Архитектурные Решения\*\*



\*\*Дата:\*\* 27.08.2025



\*\*Статус:\*\* Определение фундаментальной архитектуры.



\*\*Описание:\*\*

Этот пост фиксирует исходные принципы и решения, принятые на старте проекта, которые служат основой для дальнейшей разработки.



\*\*Ключевые принятые решения:\*\*



1\.  \*\*Основной стек\*\*:

&nbsp;   \*   \*\*Среда разработки\*\*: PHP для динамической сборки страниц из компонентов на локальном сервере.

&nbsp;   \*   \*\*Продакшн\*\*: Статические HTML, CSS, JS файлы, сгенерированные скриптом сборки для максимальной производительности и SEO.



2\.  \*\*Архитектура компонентов\*\*:

&nbsp;   \*   \*\*Структура\*\*: Каждый компонент изолирован в своей директории `components/{имя-компонента}/`.

&nbsp;   \*   \*\*Состав\*\*: Компонент включает `{имя}.php` (шаблон/логика), `{имя}.json` (данные/настройки) и, при необходимости, `script.js` (локальный скрипт).



3\.  \*\*Глобальная конфигурация\*\*:

&nbsp;   \*   Файл `site.json` в корне проекта служит единым источником правды для глобальных настроек (цветовая палитра, типографика, брейкпоинты, размеры контейнеров). Эти данные используются для генерации CSS-переменных.



4\.  \*\*Управление уникальностью экземпляров компонентов (HTML ID)\*\*:

&nbsp;   \*   \*\*Проблема\*\*: При использовании одного компонента несколько раз на странице возникали конфликты HTML `id`.

&nbsp;   \*   \*\*Решение\*\*: В PHP-файле каждого компонента генерируется уникальный базовый ID, основанный на имени его директории (`$componentBaseId = basename(\_\_DIR\_\_);`). Все внутренние `id` элемента генерируются с этим префиксом (например, `$componentBaseId . '-header'`), что гарантирует их уникальность.



5\.  \*\*Изоляция JavaScript\*\*:

&nbsp;   \*   \*\*Проблема\*\*: Как избежать конфликтов и обеспечить, чтобы JS компонента влиял только на свой экземпляр.

&nbsp;   \*   \*\*Решение\*\*: Если у компонента есть `script.js`, его PHP-файл генерирует небольшой `inline`-скрипт. Этот скрипт ожидает `DOMContentLoaded`, находит родительский элемент компонента по его уникальному ID и передает этот элемент в функцию-инициализатор из `script.js`. Весь JS-код работает только в контексте этого элемента (`element.querySelector(...)`).
