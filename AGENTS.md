# WebForge — Instructions for AI Agents

## Commands
- Нет команд. Архитектурный проект (генераторы ещё не написаны).

## Conventions
- PHP 8.3 для разработки, статика для деплоя
- webforge.json — SSOT (структура, контент, тема, медиа, schema)
- Без фреймворков — HTML/CSS/JS с нуля
- Mobile-First (320px вверх)
- Минимум JavaScript
- SEO-first (Critical CSS, Schema.org, OG)
- AI-friendly архитектура

## Structure
- `README.md` — философия и архитектура
- `docs/CONTEXT.md` — контекст разработки
- `schema.mermaid` — диаграмма архитектуры
