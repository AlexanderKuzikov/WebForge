# PHP Static Site Generator с Компонентной Архитектурой

Этот проект представляет собой систему для разработки сайтов с использованием PHP и компонентного подхода, с последующей компиляцией в оптимизированные статические HTML, CSS и JS файлы.

Основная цель — создание максимально быстрых и SEO-дружелюбных сайтов. Процесс разработки ведется в динамическом окружении на локальном PHP-сервере, а для публикации генерируется чистая статика.

## Ключевая философия

1.  **Без фреймворков**: Весь код HTML, CSS и JavaScript пишется с нуля. Идеи для дизайна могут быть заимствованы, но реализация всегда кастомная.

2.  **Mobile-First**: Стилизация начинается с мобильных устройств (минимальная ширина 320px) и расширяется для больших экранов с помощью медиа-запросов. Используются относительные единицы измерения (`rem`, `em`, `%`, `vw`/`vh`).

3.  **PHP для разработки, Статика для деплоя**: Разработка ведется на PHP для удобства и динамического подключения компонентов. Финальный результат — статические файлы, не требующие серверной обработки.

4.  **Минимум JavaScript**: Приоритет отдается решениям на чистом HTML и CSS. JavaScript используется только там, где без него не обойтись.

## Архитектура проекта

### Структура файлов

Проект имеет следующую ключевую структуру файлов:

*   **Корневая директория проекта**
    *   `components/`: Директория, содержащая все компоненты.
        *   `header/`: Пример директории компонента "header".
            *   `header.php`: PHP-шаблон компонента.
            *   `header.json`: JSON-файл с данными и настройками компонента.
            *   `script.js`: (опционально) Локальный JavaScript для компонента.
        *   ... (другие директории компонентов)

    *   `css/`: Директория для файлов стилей.
        *   `base.css`: Файл для сбросов стилей и глобальных CSS-переменных.
        *   `layout.css`: Файл для стилей макета (контейнеры, сетка).
        *   `components.css`: Файл, содержащий стили для всех компонентов.

    *   `build/`: Директория для финальной статической сборки проекта.

    *   `site.json`: Глобальный конфигурационный файл сайта.
    *   `index.php`: Точка входа для разработки на локальном PHP-сервере.
    *   `build.php`: Скрипт для запуска процесса статической сборки.

---

*   **Компоненты**: Каждый компонент находится в своей папке и состоит из `php`-шаблона (логика и разметка), `json`-файла (данные и настройки) и опционального `js`-файла.

*   **`site.json`**: Глобальный конфигурационный файл, хранящий настройки темы (цвета, шрифты, брейкпоинты), а также общие данные (логотип, контакты и т.д.).

*   **CSS**: Стили разделены на базовые, макетные и компонентные. CSS-переменные генерируются из `site.json`.

### Процесс работы

1.  **Разработка**:
    *   Вы работаете с файлами в папке `/components` и редактируете `site.json`.
    *   Результат в реальном времени отображается на локальном PHP-сервере.
    *   PHP динамически собирает страницу из компонентов, читая их `.json` файлы.

2.  **Сборка**:
    *   Запускается скрипт сборки (например, `build.php`).
    *   Скрипт генерирует статические HTML-файлы.
    *   Все CSS и JS файлы объединяются и минимизируются.
    *   Готовые к публикации файлы помещаются в папку `/build`.

## Начало работы

### Требования

*   Локальный веб-сервер с поддержкой PHP (например, XAMPP, Open Server, или встроенный сервер PHP).

### Разработка

1.  Запустите локальный сервер в корне проекта.

2.  Откройте проект в браузере. `index.php` соберет страницу из компонентов.

3.  Вносите изменения в файлы `.php`, `.json`, `.css`. Изменения будут видны сразу после обновления страницы.

### Сборка проекта

Для генерации статической версии сайта запустите скрипт сборки из командной строки:
