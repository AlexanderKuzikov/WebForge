# PHP Static Site Generator с Компонентной Архитектурой (WebForge)

Этот проект представляет собой систему для разработки сайтов с использованием PHP и компонентного подхода, с последующей компиляцией в оптимизированные статические HTML, CSS и JS файлы.

Основная цель — создание максимально быстрых и SEO-дружелюбных сайтов. Процесс разработки ведется в динамическом окружении на локальном PHP-сервере, а для публикации генерируется чистая статика.

## Ключевая философия

1.  **Без фреймворков**: Весь код HTML, CSS и JavaScript пишется с нуля. Идеи для дизайна могут быть заимствованы, но реализация всегда кастомная.

2.  **Mobile-First**: Стилизация начинается с мобильных устройств (минимальная ширина 320px) и расширяется для больших экранов с помощью медиа-запросов. Используются относительные единицы измерения (`rem`, `em`, `%`, `vw`/`vh`).

3.  **PHP для полноценной разработки, Статика для деплоя**: Разработка ведется в полноценной PHP-среде, сгенерированной из декларативного описания. Это обеспечивает максимальное удобство отладки и использования привычных PHP-инструментов. Финальный результат — статические файлы, не требующие серверной обработки.

4.  **Минимум JavaScript**: Приоритет отдается решениям на чистом HTML и CSS. JavaScript используется только там, где без него не обойтись.

## Архитектура проекта

### Структура файлов

Проект имеет следующую ключевую структуру файлов:

*   **Корневая директория проекта**

    *   `components/`: Директория, содержащая PHP-файлы всех компонентов.

        *   `header/`: Пример директории компонента "header".

            *   `header.php`: PHP-шаблон компонента, который принимает данные через переменные.

        *   ... (другие директории компонентов)

    *   `css/`: Директория для файлов стилей.

        *   `base.css`: Файл для сбросов стилей и глобальных CSS-переменных.

        *   `layout.css`: Файл для стилей макета (контейнеры, сетка).

        *   `components.css`: Файл, содержащий стили для всех компонентов.

    *   `_dev_site/`: **Новая директория.** Здесь будет генерироваться полноценный, динамический PHP-сайт для фазы разработки.

    *   `build/`: Директория для финальной статической сборки проекта.

    *   `webforge.json`: **Единственный Источник Правды (SSOT).** Глобальный конфигурационный файл, содержащий всю структуру сайта (страницы, их компоненты и данные), настройки темы (цвета, шрифты, брейкпоинты), а также общие данные (логотип, контакты и т.д.).

    *   `webforge_page_structure_templates.json`: (Опционально) Файл с JSON-описаниями структурных шаблонов страниц для PageBuilder. Эти шаблоны определяют скелет страницы с компонентами-плейсхолдерами и настройками макета.

    *   `webforge_php_generator.php`: **Новый скрипт.** Скрипт, который читает `webforge.json` и генерирует PHP-сайт в директории `_dev_site/`.

    *   `build.php`: Скрипт для запуска процесса статической сборки.

### Процесс работы

1.  **Декларативное описание (`webforge.json`)**:
    *   Вся структура и контент сайта описываются в файле `webforge.json`. Вы не работаете напрямую с файлами страниц, а описываете их структуру, используемые компоненты и их данные.

2.  **Генерация PHP-сайта для разработки**:
    *   Запускается скрипт `webforge_php_generator.php`.
    *   Этот скрипт читает `webforge.json` и генерирует **полноценный PHP-сайт** в директории `_dev_site/`. Он создает отдельные `.php` файлы для каждой страницы, копирует PHP-компоненты, генерирует PHP-макеты и все необходимые ассеты.
    *   **Фаза Разработки**: Разработчик запускает локальный PHP-сервер, указывая корневой директорией `_dev_site/`. Получается полностью функциональный, динамический PHP-сайт. Это позволяет использовать стандартные средства отладки PHP, работать в привычной среде разработки. PHP-файлы компонентов получают данные из `webforge.json` через контекст рендеринга.

3.  **Статическая Сборка**:
    *   Когда PHP-сайт в `_dev_site/` готов и протестирован, запускается скрипт `build.php`.
    *   Этот скрипт "обходит" сгенерированный PHP-сайт в `_dev_site/`, инклудит PHP-файлы страниц, захватывает их вывод и сохраняет как статические HTML-файлы в папке `build/`.
    *   Все CSS и JS файлы из `_dev_site/` (или из исходных `css/` и `components/`) объединяются и минимизируются.
    *   Готовые к публикации статические файлы помещаются в папку `/build`.

## Начало работы

### Требования

*   Локальный веб-сервер с поддержкой PHP (например, XAMPP, Open Server, или встроенный сервер PHP).

### Разработка

1.  **Подготовьте `webforge.json`**: Определите структуру вашего сайта, страницы, компоненты и их данные в файле `webforge.json`.
2.  **Сгенерируйте PHP-сайт для разработки**:
    ```bash
    php webforge_php_generator.php
    ```
    Это создаст или обновит содержимое директории `_dev_site/`.
3.  **Запустите локальный PHP-сервер**: Укажите корневой директорией **`_dev_site/`**.
    *Например, с использованием встроенного сервера PHP:*
    ```bash
    php -S localhost:8000 -t _dev_site/
    ```
4.  **Откройте проект в браузере.** `index.php` (или другие страницы) в `_dev_site/` будут динамически отображать ваш сайт.
5.  **Вносите изменения**: Изменяйте `webforge.json` или PHP-файлы компонентов в `components/`. После изменений в `webforge.json`, повторно запускайте `webforge_php_generator.php` для обновления `_dev_site/`.
